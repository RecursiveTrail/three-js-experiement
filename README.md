# three-js-experiement

A Vite + React gym for WebGL / React Three Fiber experiments.

## Run

```bash
npm install
npm run dev
```

- `/` — experiment list
- `/cat-world` — backyard cat. Mash the keyboard.

```bash
npm test
```

## Cat World

Stylized Quaternius cat in a Polyhaven yard. Keys are a nudge, not a remote. Facts appear after each reaction.

Assets live under `public/assets/cat-world`.
